# File systems

A Carpentries Workbench lesson on where a file lives on Snellius, and how those paths differ on the course cluster. Home is 200 GiB and backed up. Scratch is temporary. `$TMPDIR` belongs to one job.

The source deck is `course-module-snellius-fs/slides/snellius-fs.org` in <https://github.com/HaoZeke/introduction-to-supercomputing>, branch `fix/slides-fs-source`, commit `4709c85d9b7b38b1c943486bb1bf4b328fd48a6e`. The hands-on notes and `ex1/` sit beside that deck. The deck was written by Xavier Álvarez-Farré and adapted by Rohit Goswami.
