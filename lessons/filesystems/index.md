This lesson is where a file should live on the cluster. Home is small and backed up. Scratch is large and temporary. A job has its own directory, and that directory does not last.

The last episode submits work with `sbatch`. The EESSI client container has no `sbatch`, so that episode needs Snellius or the course cluster.

::: prereq

- [ ] A terminal
- [ ] A login on Snellius or the course cluster
- [ ] You can run `pwd`, `ls`, and `cd`
- [ ] For the last episode, a machine with Slurm

:::
