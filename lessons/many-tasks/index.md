This lesson runs thousands of short tasks. A Slurm array is the first tool. QCG-PilotJob then runs those tasks inside one allocation. The last episode compares HyperQueue, Snakemake, and FireWorks on the same exercises. That episode is optional.

The hands-on tree is `episodes/files/hands-on/`. Examples 01 to 05 are the QCG module. `alternatives/` is the comparison, including `measurements/`.

::: prereq

- [ ] You can submit a Slurm job
- [ ] You can read a short Python script
- [ ] You are in this lesson's `episodes/files/hands-on` tree when you run a script

:::
