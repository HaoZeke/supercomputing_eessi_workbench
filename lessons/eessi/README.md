# Software from EESSI

A Carpentries Workbench lesson on the shared EESSI software stack. You load a module instead of installing a private copy. The hands-on target is `python3 --version` printing `Python 3.13.5` from EESSI 2025.06.

The environment-modules section of the source deck is `course-module-fundamentals-of-hpc/slides/fundamentals-of-hpc.org` in <https://github.com/HaoZeke/introduction-to-supercomputing>, branch `fix/slides-fundamentals-source`, commit `2ebb95294418d5831143e393e93b294af39464b1`. How a module file is built is a different course: <https://hpceb.rgoswami.me/> and <https://github.com/HaoZeke/what-easybuild-is-doing>.
