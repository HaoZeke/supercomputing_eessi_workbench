This lesson loads software from EESSI, a shared stack of scientific builds. You select a build with a module. You do not compile a private copy into your home directory.

The same Python is available on the cluster and in the EESSI client container. The container has no queue. A long run still belongs on the cluster.

::: prereq

- [ ] A terminal
- [ ] A login on Snellius or the course cluster, or Apptainer 1.0 or newer for the client container
- [ ] The setup page for the machine you will actually use

:::
