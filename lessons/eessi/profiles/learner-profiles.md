## Noor

Noor writes Python on a laptop and has not loaded a module. On the laptop, `pip install` into the home directory is how a missing package gets solved. On the cluster that copy fills a small home, and a second person cannot name the same build.

Noor needs one command sequence that ends in a version string from the shared stack. The win is `python3 --version` printing `Python 3.13.5` after `module load Python/3.13.5-GCCcore-14.3.0`. A second win is leaving `QCG-PilotJob` alone when `module spider` cannot find it in EESSI.
