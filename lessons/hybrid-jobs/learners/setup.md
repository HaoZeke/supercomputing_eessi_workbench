---
title: Setup
---

You need a terminal on Snellius or the course cluster. Copy `episodes/files/hands-on/` to the cluster and submit from the exercise directory. The scripts compile the `.c` file in the current directory.

::: sites ssh-login
:::

::: sites module-init
:::

The job scripts load `foss/2025a` after the 2025 stack. That module provides `gcc` and `mpicc`.
