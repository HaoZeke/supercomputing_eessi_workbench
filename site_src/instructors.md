# Class plan

The Introduction to HPC class lasts four hours, including a 15-minute break. Start with the [Open OnDemand setup guide](/setup.html), then follow the Part I timetable on the [homepage](/#part-one).

The core route covers access, architecture, EESSI, the first batch job, resource requests, Python/OpenMP, a small job array and keeping results. Keep the final ten minutes for the exit check: show a job ID, the correct sum and pi results, the loaded environment and the output location.

The optional storage, workflow, hybrid and performance previews replace 03:20-03:50 only when the core checkpoints are met. They do not add time to the class.

[Download the learner slides](/downloads/introduction-slides.zip). The [classroom branch](https://github.com/HaoZeke/introduction-to-supercomputing/tree/course/maastricht-20261028) contains the audited exercises while upstream changes are under review. Detailed teacher workbooks and worked teaching notes are distributed privately.
