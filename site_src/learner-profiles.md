# Learner profiles

Three people this day is for. The exercises assume a terminal and a text editor. They do not assume a previous batch job.

## Noor

Noor writes Python on a laptop and has just been told the data set is on Snellius. Noor can use a terminal and has not seen a module or a queue. Noor needs the fundamentals lesson and the EESSI lesson before any of the later material makes sense. The win for Noor is one `sbatch` that runs, and a clear rule about which directory holds the result.

## Idris

Idris has logged in before and has a directory of scripts in `/home`. Jobs sit in the queue, or they die at the start because the module was loaded in a different order last time. Idris needs the scheduler episode, `module purge` before `module load`, and the file system table. The array is the part Idris came to see.

## Sam

Sam already submits jobs and is now generating thousands of one-second tasks. The queue time is longer than the work. Sam can skim fundamentals, should still do the file system lesson because the outputs are many small files, and should spend the afternoon on QCG-PilotJob and the comparison with HyperQueue, Snakemake, and FireWorks. The performance lesson is there so Sam can say whether more cores helped, with a number.
