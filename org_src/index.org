This lesson is a one-day introduction to a shared supercomputer. You will log in, load software from the EESSI stack, submit Slurm jobs, move data without drowning the file system, run many small tasks, and take a first look at timing and scaling.

This lesson has six episodes. Each one is about half an hour of teaching plus a short exercise. The slide decks for the SURF course sit beside it. The instructor notes say which deck matches which episode.

#+begin_prereq

- [ ] You can open a terminal and move around a file system
- [ ] You can edit a plain text file
- [ ] You have a Snellius account, a seat on the course cluster, or the EESSI client container from the setup page

#+end_prereq

The course cluster is a small Magic Castle cluster on SURF Research Cloud. It has the same kinds of parts as Snellius: a login node, Slurm, a shared file system, and the EESSI software stack. The numbers are smaller. Commands you practice there are the commands you will use on Snellius, with a shorter resource request.

If you cannot reach either machine today, every episode has a fallback you can run in the EESSI client container. That container mounts the same software repository the cluster uses. It does not give you a batch queue. You still run the program the job would have run.

#+begin_callout
The login node is shared. You prepare work there. You do not run the long computation there.
#+end_callout
